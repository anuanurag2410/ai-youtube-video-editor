# Technology B-roll Assets

Place approved transparent PNG logos/screenshots here.

Recommended structure:

```
assets/technologies/
  databricks/logo.png
  spark/logo.png
  pyspark/logo.png
  python/logo.png
  sql/logo.png
  snowflake/logo.png
  bigquery/logo.png
  airflow/logo.png
  aws/logo.png
  azure/logo.png
  gcp/logo.png
  delta-lake/logo.png
```

The Smart Edit Director already produces asset IDs in this format.

Current V3.1 behavior:
- if logo assets are not present, the renderer shows a clean technology name card
- the next visual-asset milestone will replace those cards with actual logo/image B-roll
- use only assets you are comfortable using in your videos
